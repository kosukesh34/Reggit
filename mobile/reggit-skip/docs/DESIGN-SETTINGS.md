# Skipのデザイン設定

管理画面の「設定 → デザイン・ホーム」で設定します。アプリは起動時にプロジェクトの設定を取得します。保存後はアプリを起動し直して反映を確認してください。

- 「ホームに会員証を表示する」: ホームを「画像 → 会員コード（バーコード部分）→ メニュー」の順に表示します。コードをタップすると提示用シートが開きます。初期値はオンです。未登録時には表示しません。
- ヘッダー・フッター・ハンバーガーメニュー: 「プロフィール編集」を選ぶと登録情報の編集フォームへ直接進みます。会員証は「会員」から引き続き開けます。
- 会員コード: ホーム・会員画面ともに、コードの拡大は下から開くシートです。閉じる操作と提示案内を共通にしました。
- ホームのメニュー: 有効な機能を並べ、空のマスや内部キーは表示しません。リスト・2列・3列の既存レイアウト設定を使えます。
- ハンバーガーメニュー: 設定済みの場合は管理画面で保存した項目と順序を反映します。

サーバー反映時は `php artisan migrate` を実行し、Skipアプリを再ビルドしてください。会員証のホーム表示はSkip向けで、LINEのホームには追加していません。

## プロフィール編集とボタン配色

プロフィール編集は基本情報・住所・その他の情報に分け、重複する見出しを削除しました。下部の「変更を保存」はキーボード表示中も操作できます。必須項目のエラーは保存を試した後に表示します。

「アプリのボタン・配色」では、ヘッダーボタンの文字／アイコン、フッター全体の背景、フッターボタンの通常時／選択中の文字・アイコンと選択中の背景を指定できます。ヘッダー全体の背景は既存の「ヘッダー → 背景色」で設定します。未設定の配色は既存のテーマを引き継ぎます。

アプリ独自のアイコン・説明ラベルをFont Awesomeの同梱フォントで描画します。Walletの公式ボタンやOS標準のキーボード・ピッカーの表示はそれぞれの標準UIを使用します。

## タブによる整理

デザイン設定を「ホーム」「ヘッダー」「フッター」「メニュー」「商品一覧」「ボタン」の6タブに分けました。ヘッダー・フッターの色は各タブで編集します。入力はタブを切り替えても保持され、まとめて保存されます。保存後も編集していたタブに戻ります。

「ボタン」では主要・補助ボタンの背景と文字／アイコンの色を設定します。保存・予約・商品追加などの共通ボタンに反映し、会員ランクや全体のテーマ色とは独立しています。

Skipのヘッダー中央には設定済みの画像を縦横比を維持して表示します。画像未設定時は店舗名を表示します。左右のメニューボタンと画像が重ならないように配置しています。

ヘッダー左右のボタン背景はヘッダー本体と同じ色に統一します。ヘッダーは共通の固定領域に表示し、メニューから開いた画面や詳細画面では左ボタンを「戻る」に切り替えます。アプリの背景は淡いグレー、カードは白、入力欄はグレーにし、プロフィール編集の文字と必須表示のコントラストを確保しています。

ヘッダーボタン背景色と通常時のフッターボタン背景色は個別設定を廃止し、それぞれヘッダー／フッター全体の背景色と同じになります。メニューを開いている間は左のアイコンをハンバーガーのまま表示します。

保存済み設定でホーム用アイコンが他の機能にも使われている場合は、その機能の標準アイコンへ補正します。ホーム画面・ヘッダー・フッター・ハンバーガーメニューで同じ解決規則を使い、管理画面の選択欄にも補正後の値を表示します。
