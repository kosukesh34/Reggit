# Reggit native UI direction

この文書は旧画面の仕様ではなく、現在の実装が守るデザイン契約を記録する。

## 方向性

LIFFの現在のデザインをネイティブUIとして再現し、編集的で静かなストアフロントを採用する。

- 温かい紙色の背景、白いコンテンツ面、深いフォレストグリーンの操作色、コーラルの小さなアクセント。
- 情報階層は文字サイズ、余白、区切り線で表現する。影や装飾的なグラデーションに頼らない。
- 同じ角丸カードを反復しない。リストは原則として1列にし、行全体を44pt以上の操作領域にする。
- トップレベルはシステムの `TabView`、階層遷移は `NavigationStack` を使う。
- 閲覧画面の作成操作はナビゲーションバーへ配置する。注文確定、予約確定など、完了に直結する操作だけを画面下部へ固定する。
- 商品、サービス、施術、予約枠のいずれにも使える語彙とレイアウトにする。

## 主要画面

- ホーム: 店舗名とプロフィール導線を最上部へ置き、デモ/店舗画像を一つの象徴的な要素として使う。会員証は横長の黒い行、機能入口は2列カードではなく説明付きの1列リスト。
- 商品・サービス: 検索、カテゴリ、商品行の順。商品は画像・名称・説明・価格・数量を一つの行にまとめ、カートがある時だけ下部に確認導線を出す。
- 注文: 状態フィルターの下に区切り線ベースの履歴を置く。
- クーポン: LIFFと同じ縦型カードで画像を中央表示する。利用開始前・利用済み・期限切れは視覚的に減衰し、履歴には件数と再利用不可を明示する。
- 予約: 一覧画面では右上の追加ボタンを使い、作成フォームの確定だけを下部に固定する。
- 会員証: LIFFと同じフォレストグリーンの会員面に、残高・ランク・提示コードを明快に分離する。
- プロフィール: APIの表示設定と順番をそのまま反映する。編集はネイティブ `Form`、保存は右上に配置し、通信中と入力不備では無効化する。

## テーマ

`AppDesign` に色、角丸、面を集約する。標準テーマはLIFFと同じフォレストグリーンと紙色。`AppConfig.primaryColor` と `BrandPalette` の経路は維持し、将来 `usesStoreTheme` を有効化した場合も操作色だけが店舗色へ変わる。背景色や文字色まで店舗色で上書きしない。

## デモ素材

`Sources/Reggit/Resources/Module.xcassets/DemoStoreHero.imageset/demo-store-hero.png` はImageGenで作成した権利上安全な店舗イメージ。ホームのヒーローだけに使い、商品画像、プロフィール画像、ロゴの代用品にはしない。

## 根拠

- [Lazyweb調査](https://www.lazyweb.com/agentic-search/5cc0ac50-00ae-446c-84c1-6df8c1af40b0): 100社の画面を1社1件で確認し、会員証30件、プロフィール編集30件を追加確認した。参照企業がスマレジを利用していることを示すものではない。
- Apple Human Interface Guidelines: システムナビゲーション、44pt以上の操作領域、主要操作の到達性、Dynamic Typeを基準とする。

## 検証

`swift test` で共通Swiftコードのビルドと単体テストを確認する。実機確認ではiPhone SE相当から大型端末までの文字折返し、キーボード、セーフエリア、Apple Walletボタンを確認する。
