# 複数店舗の実装と運用

更新日: 2026-09-28

## 店舗を追加する

1. システム管理者またはプロジェクト管理者で対象プロジェクトの管理画面にログインする。
2. 「設定 → 店舗・担当権限」を開く。URL は `/admin/{project_key}/stores`。
3. 店舗名を入力し追加する。店舗キーは未入力なら自動設定。住所・電話番号・スマレジ店舗ID等は「識別キー・外部連携の設定」にまとめる。
4. 店舗の担当者を選び保存する。担当者はあらかじめ対象プロジェクトに所属する必要がある。
5. 最上部に表示する現在の店舗名をクリックして店舗を選ぶ。サイドバーの「設定」の子メニューにも現在の店舗名を表示する。本部は「全店舗」を選択できる。

店舗管理者・スタッフは担当店舗のみ選択でき、店舗追加と担当者の変更はできない。担当店舗がない場合は会員・取引を表示しない。複数担当の管理者は取引を作成する前に具体的な店舗を選択する。

## 共通情報と店舗情報

| 情報 | 保存・閲覧範囲 |
|---|---|
| 会員証・会員番号・ポイント残高・ランク | プロジェクト共通 |
| 会員閲覧 | 本部は全会員、支店は担当店舗の利用関係がある会員 |
| 注文・予約・順番待ち・来店・売上・取引履歴 | 取引が行われた店舗 |
| 会員メモ | 複数店舗では選択店舗ごと |
| 営業時間・休業日・注文モード・注文通知・予約枠・定員・順番待ち設定 | 選択店舗の上書き設定。未設定はプロジェクト設定を利用 |
| 商品・価格・在庫・クーポン定義・スタンプ定義・タグ・ブランド設定 | 現段階ではプロジェクト共通。本部が編集 |
| 店舗アプリ端末の認証 | 発行店舗に固定 |

会員は注文・予約・受付・来店などの取引によって利用店舗に関連付く。同一会員が複数店舗を利用した場合、その店舗それぞれから会員を確認できるが、他店舗の取引と店舗メモは表示しない。店舗を選んで画面を開くだけでは利用関係を作らない。

LIFFでは複数店舗があると店舗選択を表示する。選択値は `?store_id={id}`。注文・予約・順番待ちは選択店舗で受付する。会員証と残高は共通。

## プロフィールの対象店舗

プロフィールと管理画面の会員編集に「対象店舗」を追加。スマレジ会員APIの `storeId`（対象店舗ID）に対応する。アプリでは店舗名で選択し、ローカル `members.customer_store_id` を保存する。送信時は店舗の `smaregi_store_id` に変換する。対応未設定なら外部IDを送信しない。受信時も同一プロジェクトの対応店舗へ変換し、未対応のIDでは既存値を上書きしない。

プロフィール項目設定で表示・必須を変更できる。初期値は表示あり・任意。対象店舗を設定すると会員と店舗の利用関係を追加する。変更・解除しても過去の利用店舗との関係は削除しない。ポイント残高や過去の取引店舗も変えない。

## 一斉配信

- 支店での「全員」は選択店舗の利用会員に限定する。他店舗のみ利用の会員は対象に含めない。
- 本部の「全店舗」はプロジェクト全体の会員を対象とする。特定店舗を選択すればその店舗の会員が対象。
- 個人指定・条件指定にも同じ店舗制限を適用する。
- 対象会員は既存の `target_member_ids` JSON、対象店舗は `store_ids` JSON に保存する。
- LINE・Pushの送信対象にも店舗制限を再適用する。
- 限定配信のお知らせと画像は対象会員にのみ公開する。他店舗のみの会員・未ログイン利用者は確認できない。
- 予約配信の実行時に作成者の権限と店舗の有効状態を確認する。失効時は `held` で保留する。現段階では再承認ボタンがないため、本部から対象を確認して新しい配信を作成し、保留配信を削除する。

共通クーポン自動配布・登録後配信の設定は本部で管理する。任意の複数店舗をチェックボックスで選ぶ配信、店舗別通知拒否設定、送信プロバイダー側の専用冪等キーは今回の実装には含まない。

## 移行と互換性

マイグレーションで既存プロジェクトに `main` 店舗を作成し、既存の会員・担当者・取引を関連付ける。初期店舗の営業時間等は既存設定を参照する。1店舗の間は従来の設定・メモ運用と公開お知らせを維持する。2店舗目を追加すると共通情報の編集は本部に限定される。

ローカル開発DBに移行を適用済み。適用前のバックアップは `/tmp/reggit-before-multistore-20260928.sql`。本番はバックアップ後に `php artisan migrate` を実行する。複数の既存プロジェクトを自動統合しない。会員・LINE・スマレジ契約の対応を確認して別途移行する。

スマレジ取引は店舗IDの対応を設定する。複数店舗で対応がない取引は誤って別店舗に割り当てず同期をスキップしてログを残す。
