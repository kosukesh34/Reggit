# スタンプカード・達成特典・取引キャンセル（CS / Q&A）

店舗・CS がお客様へ回答するときの参照です。実装（2026-08 時点）に基づきます。店舗のカード設定（達成後の動き）で一部変わります。

**お客様へそのまま使える結論**

> キャンセルしたお会計分のスタンプは戻ります。そのお会計で付いた達成クーポンは、まだ使っていなければ発行を取り消します。すでに使っている場合は回収しません。未使用のまま取り消したあと、再度カードが埋まれば同じクーポンをまたお渡しします。

---

## 1. 回答の原則（先にこれ）

| 項目 | 仕様 |
|------|------|
| スタンプ | そのお会計で付いた分は、キャンセル（または返品）で戻る |
| 達成クーポン（未使用） | そのお会計が原因で付いた分は、キャンセルで発行取消（削除） |
| 達成クーポン（使用済み） | 回収しない。未使用に戻すこともない |
| 同じクーポンの再発行 | 同じ周・同じ個数の達成は1回だけ。別の周ならまた出す。未使用取消後に同じ周を再達成すれば出す |
| 同じカードの2周目 | スタンプはまた貯まる。2周目の達成でもクーポンを出す（1周目分とは別枚） |
| 複数会計のキャンセル | キャンセルした会計で付いた未使用だけ取り消す。他の会計分は残す。同じ会計の再キャンセルは何もしない |
| ガチャ（スタンプ達成） | 周ごとに別権利。会計キャンセルでは取り消さない |
| ガチャ（お会計そのもの） | 未使用ならキャンセルで回収。使用済みは回収しない |

管理画面の手動スタンプ減算や、付与QRからの達成では発行元が会計に紐づかないため、会計キャンセルではクーポンを消しません。

---

## 2. カードの「達成後の動き」

管理画面のスタンプカード設定です。未設定は **同じカードを繰り返す** です。

| 設定（画面の文言） | 必要数（例: 10個）に達したあと | 追加のスタンプ |
|--------------------|--------------------------------|----------------|
| 同じカードを繰り返す | 枠をリセットし、余りは次周の所持になる | 付き続ける |
| 1周で終了する | そのカードは終了 | 付かない |
| 達成したら別のカードに切り替える | 達成カードは履歴に残る。余りは次のカードへ | 次のカードに付く |

お客様のアプリでは、切り替え前のカードが終わるまで次のカードは見えません。終わったカードは履歴側に残ります。

### 表示の見方（同じカードを繰り返す）

画面の個数は「今の周で埋まっている数」です。何周したかは別カウントです。

- 10個カードで累計14個 → 表示は **4個**（1周達成＋余り4）
- 10個カードでちょうど20個 → 表示は **0個**（2周達成）

---

## 3. 達成特典の種類

カードのマイルストーン（例: 10個でクーポン）で出るものと、クーポンマスタの発行トリガーで出るものがあります。

| 特典 | いつ付くか | 同じ会員への再発行 |
|------|------------|--------------------|
| マイルストーンのクーポン | その加算で指定個数を跨いだとき | 周ごと・取引ごとに1枚。同じ周の再到達では出さない |
| 「スタンプカード達成時」トリガーのクーポン | カードが初めて達成扱いになったとき | 同上（会計に紐づく達成なら未使用取消の対象） |
| マイルストーンのガチャ | 指定個数を跨いだとき | **周が違えば付き得る**（会計キャンセルでは取り消さない） |
| お会計に紐づくガチャ | スマレジ取引の付与条件を満たしたとき | 取引ごと。キャンセル時は下記 |

「同じカードを繰り返す」では、達成日時を立てないため、「スタンプカード達成時」トリガーは動きません。繰り返すカードのクーポンはマイルストーン設定側です。

減算・キャンセルでは特典を付けません。

## 4. よくある問い合わせ

### Q. 9個持っているときに、お会計で5個付いた。クーポンを使ったあと、その会計をキャンセルしたらスタンプは戻りますか？

**戻ります。** その会計で付いた5個が取り消され、所持は **9個** に戻ります（必要数10個のカード）。

履歴には取消の行が残ります。画面上すぐ0に消えるわけではなく、プラスとマイナスが残ります。

**回答例**

> キャンセルしたお会計で付いたスタンプは取り消され、キャンセル前の個数に戻ります。すでにご利用いただいたクーポンは戻りません。

---

### Q. そのとき付いたクーポンは回収されますか？ 未使用なら？

**未使用なら発行を取り消します。使用済みなら残します。**

そのお会計（スマレジ取引）でスタンプ達成したために付いたクーポンだけが対象です。使用済みクーポンが未使用に戻ることはありません。

**回答例**

> まだ使っていない達成クーポンは、キャンセルしたお会計分の発行を取り消します。すでにご利用済みのクーポンは回収できません。

---

### Q. キャンセル後、もう一度お会計してスタンプが貯まったら、クーポンはもう一度もらえますか？

**未使用のまま取り消された場合は、同じ周を再達成すればもらえます。** 使用済みでクーポンが残っている場合、同じ周では再発行しません。別の周（2周目）なら新しい枚を出します。

**回答例（未使用でキャンセル）**

> 未使用のクーポンは取り消されています。もう一度スタンプが貯まれば、同じ達成クーポンを再度お渡しします。

**回答例（使用済みでキャンセル）**

> すでにご利用いただいたクーポンは残ったままです。同じ周の分をもう一度お付けすることはできません。2周目を達成された場合は、新しい枚をお渡しします。

---

### Q. 「同じカードを繰り返す」設定でも同じですか？ 2周目はクーポンが付きますか？

**周が違えば出ます。** 1周目で出したクーポンが残っていても、2周目の達成では別枚を出します。同じ周をもう一度跨いだだけ（減算して足し直す、使用済みのままキャンセルして再会計）では出しません。

未使用のままその周の会計をキャンセルした場合は、その会計で付いた分だけ発行取消します。他の周・他の会計で付いたクーポンは残ります。

**回答例**

> 同じスタンプカードを2周達成された場合は、達成クーポンも2枚お渡しします。キャンセルした場合は、そのお会計で付いたまだ使っていない分だけ取り消します。

---

### Q. 「1周で終了する」カードで、9個＋5個の会計をキャンセルしたら？

必要数で打ち止めになるため、実際に付くのは10個までの不足分（この例では1個）です。余り4個は捨てます。

キャンセルでは付いた1個だけ戻すので、所持は **9個** に戻ります。カードは未達成に戻り、再会計でまた貯められます。クーポンの回収・再発行は上と同じです。

---

### Q. ガチャはどうなりますか？

| 由来 | キャンセル時 |
|------|----------------|
| お会計（スマレジ取引）のガチャ | まだ回していない権利は削除。当たって未使用のクーポンは回収。当たって使用済みは回収しない |
| スタンプ達成のガチャ | 会計キャンセルでは取り消さない |

スタンプ達成ガチャを回して当たったクーポンを使ったあとで会計キャンセルしても、そのクーポンは回収しません。

---

### Q. 返品のときは？

キャンセルと同じです。スタンプは戻り、その取引で付いた達成クーポンは未使用なら発行取消、使用済みなら残します。購入ガチャの未使用分は回収します。

---

### Q. 店舗の管理画面でスタンプを減らした場合は？

スタンプ残高は減りますが、達成クーポンは取り消しません（会計との紐づきがないため）。クーポンが残っているあいだは、また貯めても同じクーポンは再発行しません。

---

## 5. 具体例（必要数10個・同じカードを繰り返す）

前提: すでに9個。スマレジ会計で5個付与。10個到達でクーポン発行。

### クーポンを使ったあとでキャンセル

| 時点 | スタンプ（画面） | クーポン |
|------|------------------|----------|
| 会計前 | 9個（0周） | なし |
| 会計で+5 | 4個（1周＋余り4） | 発行される |
| クーポン使用 | 変わらない | 使用済みのまま残る |
| 会計キャンセル | **9個（0周）に戻る** | **回収しない** |
| 再会計で+5 | また4個（1周） | **再発行しない** |

### クーポンを使わずにキャンセル

| 時点 | スタンプ（画面） | クーポン |
|------|------------------|----------|
| 会計で+5 | 4個（1周＋余り4） | 発行される（未使用） |
| 会計キャンセル | **9個（0周）に戻る** | **発行取消（削除）** |
| 再会計で+5 | また4個（1周） | **再発行する** |

キャンセルせず2周目に入った場合、2周目の達成でも別のクーポンが付きます。1周目分をキャンセルしても、2周目分は残ります。

---

## 6. 戻るもの / 戻らないもの

| | 会計キャンセル・返品 |
|--|----------------------|
| その会計で付いたスタンプ | 戻る |
| その会計で付いたポイント | 戻る（スマレジ側ポイント連動のときはスマレジ側の動きに従う） |
| スタンプ達成クーポン（未使用） | 発行取消（削除） |
| スタンプ達成クーポン（使用済み） | 戻らない |
| スタンプ達成ガチャの権利 | 戻らない |
| お会計ガチャ（未実施） | 削除する |
| お会計ガチャで当たった未使用クーポン | 回収する |
| お会計ガチャで当たった使用済みクーポン | 回収しない |

---

## 7. スタンプが付く経路（問い合わせ切り分け）

| 経路 | メモ |
|------|------|
| スマレジ会計 | 店舗の「会計金額あたりのスタンプ」設定。同じ取引の二重付与はしない |
| アプリ注文の完了 | 注文スタンプカード設定があるとき |
| 管理画面の会員操作 | 店舗が手動で増減 |
| スタンプ付与QR | 発行したQRを会員が読み取る。制限は発行時の設定（1日1回 / 会員1回 / 先着N名 / 期限内何度でも） |

付与QRの画像は発行直後だけ表示され、履歴には条件だけが残ります。読み取れないQRは「スタンプ付与用のQRではありません」と出ます。

---

## 8. 回答してはいけないこと

次は現状の仕様と異なります。

- 「キャンセルすれば使ったクーポンも戻ります」
- 「未使用の達成クーポンもキャンセルでは消えません」
- 「2周目では達成クーポンは出ません」
- 「1つの会計をキャンセルすると、別の会計で付いたクーポンも消えます」
- 「使用済みのまま同じ周をキャンセルしたあと、もう一度貯めれば同じ周のクーポンがもらえます」
- 「1周で終了するカードでも、10個を超えた分は次に持ち越されます」（持ち越すのは「繰り返す」「次のカードへ」だけ）

未使用取消後の再達成は自動で再発行します。使用済みで残っている場合の再発行は、管理画面からの個別発行のみです。

## 実装メモ（開発・調査用）

CS 回答には不要です。問い合わせの調査時だけ参照してください。

- 周回: `App\Enums\StampCycleMode`（未設定は `repeat`）
- 残高・周回の巻き戻し: `App\Services\Stamp\StampBalanceService`
- マイルストーン特典: `App\Services\Stamp\StampMilestoneRewardService`
- クーポン発行元: `member_coupons.issue_source_type` / `issue_source_id`（取引単位の取消）
- 配布の重複防止: `member_coupons.issue_grant_key`（カードID:周:到達個数:クーポンID）。周が違えば別配布。同じ周の再到達は出さない
- 未使用クーポンの取消: `CouponIssueService::revokeUnusedForSource`（指定した取引の未使用だけ。使用済みと他取引は残す。再実行しても安全）
- スマレジ付与・取消: `App\Services\Smaregi\SmaregiInboundAwardApplier`
- 購入ガチャの回収: `LotteryEntitlementService::revokePendingForSource`（ソースは取引ID）
- 達成時トリガー: `MemberStampObserver`（`repeat` では `completed_at` を立てない）
- 確認テスト: `tests/Feature/StampMilestoneRewardTest.php`
