# プロダクトと機能

## 目的

Reggit は会員証・ポイント・クーポン・注文・予約・順番待ちを、スマレジの会員・購買情報につなぐサービスです。便利な来店体験を入口に会員化し、購買・来店情報を使って特典と案内を届け、再来店につなげます。

飲食・物販などの店舗が、専任の分析担当者なしで運用できることを重視します。顧客は LINE または店舗のネイティブアプリを選び、店舗は不要な機能を無効にできます。

## 主な機能

| 領域 | 顧客の操作 | 店舗の操作 |
|---|---|---|
| 会員 | 登録・プロフィール・会員証・ポイント履歴・退会 | 会員検索・来店・ランク・タグ・プロフィール設定 |
| 商品・注文 | 商品検索・カート・決済・注文履歴 | 商品編集・在庫・注文状態・売上分析 |
| 予約 | 空き枠検索・登録・変更・取消 | コース・予約枠・定員・受付状態 |
| 順番待ち | 受付・番号確認・取消・QR 照会 | 店頭受付・呼出・再呼出・入店 |
| 特典 | スタンプ・クーポン・抽選・Wallet | 付与条件・カード・クーポン・抽選設定 |
| 回数券 | 購入・残り回数確認・利用 | 回数券商品・利用取消・無効化 |
| お知らせ | 一覧・既読・通知 | 公開・対象会員限定・予約配信 |
| その他 | ギャラリー・問い合わせ・住所検索 | 画像・ホーム・営業時間・外部連携 |

システム管理画面はプロジェクト・管理アカウント・API トークン・全体監査ログを扱います。複数店舗とスタッフの操作範囲は [運用](OPERATIONS.md) に定義します。

## 画面・デザイン設定

「設定 → デザイン・ホーム」で機能メニュー、順序、ラベル、アイコン、ホーム画像、ヘッダー、フッター、ボタン配色を設定します。ネイティブアプリは起動時に設定を取得するため、保存後は再起動して反映を確認します。

LIFF デザイナーは `/admin/{project_key}/settings/liff-designer` で、タブ・詳細画面のブロック配置、テンプレート、画面背景、保存済みレイアウト、プレビューを編集します。対応するブロック・アクション・上限は `LiffDesignerSanitizer` と関連 FormRequest / 設定契約を参照し、古い UI の候補を仕様として扱いません。カスタム CSS は保存時に検査します。

ネイティブのホーム会員コードは登録済み会員だけに表示し、拡大は提示用シートへ統一します。プロフィールはサーバーの項目設定・順序を反映し、必須エラーは保存操作に合わせて示します。

画面の共通基準は、重要な操作へ短く到達できること、文字と余白による情報階層、読みやすいコントラスト、押しやすい操作領域、キーボードとセーフエリアへの対応です。店舗色は設定された範囲に適用し、Wallet ボタンなど提供元の標準 UI は保ちます。ネイティブ側の色・角丸は `AppDesign` に集約します。

## 変更の判断基準

- 顧客の来店体験を簡単にするか、店舗の再来店施策を助けるか。
- 会員・来店・購買・特典を同じデータでつなげられるか。
- 設定・画面・通知・外部依存を増やしすぎず、通常運用が続くか。
- 取得情報と配信理由を顧客に説明できるか。
- テナントと店舗の境界を守り、障害・再実行でも重複しないか。
- 効果を測り、継続・廃止を判断できるか。

通知は通数を増やすことより特典利用と再来店を重視します。会員証などの基本価値は通知なしでも成立させます。店舗数が増えても全件一括処理に頼らず、ページング・キュー・店舗単位の分割を使います。
