# 管理機能の責務分離（SaaS運用）

## システム管理画面（`/system-admin/*`）
- プロジェクト管理（作成・編集）
- 管理アカウント管理（作成・編集・削除）
- APIトークン管理（発行・失効・ローテーション）
- 監査ログの全体閲覧（全プロジェクト横断）

## 店舗管理画面（`/admin/{project_key}/*`）
- 日次運用（注文・商品・会員・予約・順番待ち・クーポン・お知らせ）
- 店舗設定（基本設定・LIFFデザインなど）
- 監査ログの閲覧（現在のプロジェクトのみ）

## LIFF ID 設定場所
- `.env` の `LINE_LIFF_ID`
- 参照先: `config/line.php`

## 運用ルール（推奨）
- システム管理者は `system_admin` ロールのみ
- 店舗運用者は `project_admin / admin / staff` ロールで運用
- 日常運用は店舗管理画面、基盤運用はシステム管理画面
