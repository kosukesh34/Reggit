🍔 Reggit API

Reggit - LINE 会員証アプリ

📋 利用可能なAPIエンドポイント

商品関連:
GET /api/products - 商品一覧取得
GET /api/products/{id} - 商品詳細取得

注文関連 (認証必要):
POST /api/orders - 注文作成
GET /api/orders - 注文一覧
GET /api/orders/{id} - 注文詳細

会員関連 (認証必要):
GET /api/members/me - 会員情報取得
POST /api/members/register - 会員登録
GET /api/members/points - ポイント履歴
POST /api/members/points/add - ポイント追加

LINE Webhook:
POST /api/line/webhook - LINEからのWebhook受信

商品を読み込むボタンをクリックしてください
