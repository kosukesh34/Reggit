# 決済画像素材

取得日: 2026-10-07。外部画像への直リンクは使用せず、このディレクトリとSkipのModule.xcassetsに保存して表示する。

## PayPay

- 配布元: https://paypay.ne.jp/merchant-share/logo/
- 原本: https://paypay.ne.jp/files/merchant-share/logo/paypay_1_rgb.png
- ガイドライン: https://image.paypay.ne.jp/pdf/PayPay_brand_guideline.pdf
- PayPay株式会社のブランドロゴ1（RGB）。原本を変更せず、縦横比と画像内の余白を保持して表示。一般の自由素材ではなく、加盟店の決済手段表示として公式ガイドラインに従って利用する。

## クレジットカード

- 配布元・原本: https://github.com/lucide-icons/lucide/blob/main/icons/credit-card.svg
- ライセンス: LICENSE-lucide.txt（ISC、Lucide/Featherの著作権表示を同梱）
- 特定カードブランドを表さない汎用カードアイコン。SVG原本を保存し、currentColorを画面の文字色（#1b2924）に指定してChromiumで288×288の透過PNGへ変換。LINEとSkipで同じPNGを使用。

画像を変更する場合はWeb用ファイルとSkip imagesetの両方を更新する。

## Google Pay

- 公式配布元・表示規定: https://developers.google.com/pay/api/web/guides/brand-guidelines
- 原本アーカイブ: https://developers.google.com/static/pay/api/download-assets/Google-Pay-Acceptance.zip
- Google Pay Mark/GPay_Acceptance_Mark_800.png をそのまま保存。決済方法選択用のAcceptance Markとして縦横比、色を保持し周囲に余白を確保する。決済実行ボタンはStripe Checkoutが表示する。
