# Decision log

> Capture an architectural or product decision with rationale (lightweight ADR).

## Trigger

- "log this decision"
- "ADR for X"
- "record why we chose Y"

## Process

1. Title — `Use X for Y`.
2. Context — one paragraph.
3. Decision — one or two sentences.
4. Alternatives considered.
5. Consequences.
6. Status — `accepted` by default.
7. Date.

## Output

Place in `_documentation/AI_LEARNINGS.md` Decision Log section, or `docs/adr/` if the project adopts ADR files.
